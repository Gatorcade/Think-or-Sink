# Think-or-Sink
This is a web-based trivia game that makes you think fast! :brain:\
\
The questions in the trivia are timed, and as the timer counts down, water fills the background. :ocean:\ 
However, for each question answered correctly, the water level slightly decreases & the timer increases. :heavy_check_mark:\
Getting a question wrong doesn't remove time from the timer, as this is constantly happening anyway. :hourglass:\
Every second counts! Don't sink! :ring_buoy:\


> [!NOTE]
> Currently, the game has one category of trivia: "General Knowledge". If time permits, more categories will be added.
